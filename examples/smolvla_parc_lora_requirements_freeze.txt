# 注意点:
# - torch/torchvision/torchcodec/av/mujoco等はコンパイル済みバイナリを含むため、

#   cu130ビルドが解決された）。

#   共有ライブラリが手元に無いため）。holdout_eval評価（LIBERO-plus/robosuite/
#   MuJoCo/Wand関連）を持ち越さない前提なら、下記のうち評価専用パッケージ
#   （robosuite, mujoco, bddl, easydict, Wand等）は不要。
# - lerobotは pip版(0.6.0) と別に ~/parc_lora_workspace/lerobot の git clone
#   （huggingface/lerobot, commit 30da8e687a6dfc617fcd94afc367ac7071c376ce）を
#   PYTHONPATHで先頭に挿すことで実体を使っている。このclone側にローカルパッチが
#   2箇所あり、lerobot_local_patch.diff として同ディレクトリに保存済み
