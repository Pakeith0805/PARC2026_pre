# lerobotは "pynput>=1.7.7,<1.9.0" を無条件の必須依存として宣言しており、

# ビルドに失敗する（実際に提出して確認した）。pynput/evdevはゲームパッド等の
# 入力デバイス制御用で、SmolVLAの推論コードパスでは一切使われない
# （importチェーンを実機で確認済み）ため、lerobot本体だけvendorして
# この依存を丸ごと回避する。詳細はmy_strategy.md方針6・
# competition_analysis.mdの該当節を参照。
#
# 以下はvendorしたlerobotソースが実際に必要とする依存を、実機で1つずつ
